# Claude Design 用プロンプト

以下をそのまま Claude Design（`/design`）に貼り付けて使えます。
1 本目がメインです。2 本目以降は方向性を変えて比較したいとき用。

---

## ■ プロンプト A（メイン / 推奨）

```
社用車貸出制度のレビューサイトの UI デザインカンバスを作ってください。
ブランド名は「logoCR」。ネイティブアプリではなく Web サイトですが、
社員がスマホの QR コードから開くのが主な導線なので **モバイルファースト**でお願いします。

## サービスの背景
自動車部品メーカーの社内制度で、社員が日産車（エクストレイル／オーラ、計7台）を
福利厚生として借りられます。借りた社員が乗り心地のレビューを投稿し、
そのレビューを社内の開発部だけでなく、社外の販売店や関係企業も
QR コード／リンクから閲覧できるようにするためのサイトです。
「体験型福利厚生」「実際に乗って日産車の魅力を感じる」というコンセプトを
デザインでも感じさせたいです。

## 作ってほしいアートボード（モバイル 390x844 を基本）
1. **ホーム（レビュー一覧）** ← 最重要
2. **ホーム / 並び替えメニューを開いた状態**
3. **レビュー投稿画面**
4. **レビュー投稿 - 未入力エラー状態**（必須項目のアラート表示）
5. **車種一覧**
6. **車種詳細**
7. **静岡県販売店情報 一覧**
8. 参考として **ホームのデスクトップ版（1440x900）**

## 各画面の要件

### 1. ホーム（レビュー一覧）
- 最上部に logoCR のロゴ／サイトタイトル
- その下に **丸型（円形）のナビゲーションボタンを横並びで3つ**：
  「投稿」「車種一覧」「静岡県販売店情報」
  → Instagram のストーリーズやフードデリバリーアプリのカテゴリアイコンのような、
    円形アイコン＋下にラベルのスタイル。押したくなる見た目にしてください。
- その下に **並び替えコントロール**：「新着順 / 評価が高い順 / いいねが多い順」
- メインは **レビューの縦リスト**。YouTube のコメント欄のような、
  カード同士の境界が強すぎない、テキストが主役の読みやすいリスト型。
  1件あたりに含める要素：
  - 丸いアバター（ニックネームの頭文字を表示するイニシャルアバターでOK）
  - ニックネーム
  - 星評価（★5段階、部分的な半星も表現できるように）
  - 投稿日時（「3日前」のような相対表示）
  - 乗った車種のタグ（例：エクストレイル）
  - レビュー本文（長い場合は「続きを読む」で折りたたみ）
  - **いいねボタン**（アイコン＋件数、押した後の状態も別途見せてください）
- 一覧の「読み込み中」スケルトンと「まだ投稿がありません」の空状態も1枚ください

### 2. 並び替えメニュー展開状態
- 下から出るボトムシート、または一覧上部のセグメントコントロール。
  どちらが良いか提案してください。

### 3. レビュー投稿画面
- 入力項目は3つだけ：**ニックネーム / 星評価 / レビュー本文**
- 星評価はタップで選ぶ大きめの★5つ
- レビュー本文は複数行のテキストエリア、文字数カウンター付き
- 一番下に大きな「投稿する」ボタン
- 投稿後はホームに戻り、自分の投稿が一番上に出て確認できる、という導線が
  伝わるようにしてください（成功トーストのバリエーションも1つ）

### 4. 投稿 - 未入力エラー状態
- 1つでも空欄があると「全部必須です」というアラートが出ます。
- ブラウザ標準の alert ではなく、**サイトの世界観に合ったモーダル／トースト**の
  デザイン案も一緒に出してください（実装で置き換えられるように）
- 空欄のフィールド自体にもエラー表示を付けたバージョンを見せてください

### 5. 車種一覧
- 2つのセクションに分ける：
  - **「運行中の車」**：エクストレイル、オーラ（合計7台）。
    車の写真、車種名、グレード、色、台数、簡単な特徴、その車のレビュー平均★
  - **「人気の日産車」**：セレナ、ノート、サクラ、アリア、キックスなど。
    こちらは紹介カード中心（購買意欲を高めるのが目的）
- カードは車の写真が主役。横スクロールカルーセルかグリッドか提案してください

### 6. 車種詳細
- ヒーロー画像、スペックの要点、平均評価、その車に付いたレビュー一覧の抜粋

### 7. 静岡県販売店情報 一覧
- 静岡県の日産販売店のカードリスト
- 1件あたり：店名、住所、電話番号、営業時間、定休日、店舗写真
- エリア（東部／中部／西部）で絞り込めるタブかチップ
- **カードを押すと販売店の公式ホームページに遷移する**ことが分かるように、
  外部リンクアイコンを添えてください

## デザインの方向性
- 日産車を扱うので、**クリーン・信頼感・少しだけスポーティ**。
  白〜ライトグレーを基調に、アクセントは日産らしい **レッド**を1色。
  ただし赤を使いすぎず、面ではなく差し色として使ってください。
- 角丸は大きめ（12〜16px）、影は薄く。フラット寄りで今っぽく。
- 日本語のテキストが主役なので、日本語フォントで読みやすい行間・字間に。
  英数字とのバランスも見てください。
- 社内制度のサイトですが「社内システム感」を出さないでください。
  一般消費者向けのレビューサービスのような、見ていて楽しい雰囲気にしたいです。
- 星評価・いいね・並び替えといった操作要素は、
  押せることが一目で分かるアフォーダンスを重視してください。
- アクセシビリティ：文字と背景のコントラスト比は 4.5:1 以上、
  タップ領域は 44x44px 以上を守ってください。

## 一緒に出してほしいもの
- カラーパレット（ベース／サーフェス／テキスト／アクセント／成功・エラー）
- タイポグラフィスケール
- ボタン・入力欄・星評価・いいね・タグ・カードのコンポーネント一覧
- 各状態（通常 / ホバー / 押下 / 無効 / エラー）
```

## ■ プロンプト B（比較用 / 車の写真を主役にした案）

```
上と同じ要件で、もう1案お願いします。
今度は「レビューサイト」というより **車のブランドサイト**寄りにしてください。
ホームの最上部に運行中のエクストレイル／オーラの大きなヒーロー画像を置き、
その下にレビュー一覧が続く構成。ダークな背景に写真を映えさせる方向で、
社員の購買意欲を高めることを最優先にしたデザインにしてください。
丸型ナビ3つ（投稿／車種一覧／静岡県販売店情報）は同様に配置してください。
```

---

## ■ プロンプト C（比較用 / 徹底的に軽い案）

```
上と同じ要件で、逆に極限までシンプルな案もください。
装飾を削り、テキストと余白だけで構成する Notion / Linear のような
落ち着いたデザイン。写真は小さめのサムネイルに留め、
レビューの読みやすさとスクロールの速さを最優先にしてください。
```

---

## 使い方メモ

1. まずプロンプト A を実行し、出てきたカンバス上で直接調整する
2. 方向性に迷ったら B / C も出して 3 案を並べて社内で選定
3. 決まったデザインをもとに、実装（Next.js + Tailwind）に着手する
