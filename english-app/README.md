# Eigo Quest 🦉 — 日本人のための英語学習アプリ（MVP）

「話せる英語を、毎日3分で」。Speak / Duolingo / Quizlet の良い所を日本人学習者向けに一本化した、
**モバイルファーストのPWA**です。インストール不要でスマホのブラウザから快適に使え、
ホーム画面に追加すればネイティブアプリのように起動できます。

## 収益化に効く3本柱（市場調査ベース）
- 🎙️ **AIスピーキング（Speak型）** — 音声認識で発音をスコア化。声に出す練習で「話せる」に直結。
- 📇 **単語カード + SRS（Quizlet/Anki型）** — 間隔反復で長期記憶に定着（従来型ドリルの約3.2倍の定着率）。
- 🔥 **ゲーミフィケーション（Duolingo型）** — ストリーク・XP・レベル・1日の目標で習慣化。

さらに **Free / Premium（¥980/月）** のサブスク導線を実装済み。

## 機能
- ホーム：1日の目標リング、ストリークカレンダー、今日のひとこと
- 単語カード：表裏フリップ、発音再生（TTS）、覚えた/もう一度でSRSスケジューリング
- 復習（SRS）：忘れる頃に自動で出題（Leitnerボックス）
- スピーキング：お手本再生 → マイクで発話 → スコア＆フィードバック
- クイズ：4択で意味当て
- マイページ：統計、プレミアム訴求、設定
- 進捗は端末の localStorage に保存（オフラインでも継続）

## 技術
- 依存ライブラリなしの純粋な HTML/CSS/JS（`index.html` + `app.js` + `data.js`）
- 発音は Web Speech API（`SpeechSynthesis` / `SpeechRecognition`）。未対応ブラウザでも安全に動作。
- PWA：`manifest.webmanifest` + `sw.js`（オフラインキャッシュ・ホーム画面追加）
- safe-area 対応、下タブナビ、44px以上のタップ領域などスマホ最適化

## ローカルで動かす
```bash
cd english-app
python3 -m http.server 8080
# スマホの Safari / Chrome で http://<PCのIP>:8080 を開く
```
> 音声認識(マイク)は HTTPS もしくは localhost でのみ動作します。公開時は HTTPS 必須です。

## デプロイ
静的ファイルのみなので GitHub Pages / Vercel / Netlify にそのまま公開できます。
公開URLの `/english-app/` を開けばスマホでそのまま利用可能です。
